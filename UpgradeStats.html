UpgradeStats System

This code system is used in my game to upgrade my players’ stats. It works by the player putting a number of stat points into an amount box, where it checks if the player has the amount of stat points and if the player has the amount, it adds it to the stats you choose. The 3 stats in my game were strength, speed, and health. Also, if you added stats to health, you would get 10+ each time. Moreover, it healed you for 10 each time. Before I added this code, you had to add one point at a time, which was much slower.
